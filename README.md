# Sailors Pet Supplies

### Mga file

- `config.php` — Settings, database connection, auto-setup ng tables at owner account, at mga helper (login check, flash message)
- `header.php` — Menu sa taas (customer at staff)
- `footer.php` — Dulo ng page at Bootstrap JavaScript
- `index.php` — Catalog ng customers, inquiry form, at thank you page
- `login.php` — Login at logout ng staff
- `dashboard.php` — Staff home na may quick stats at alerts
- `inquiries.php` — Approve o reject ng inquiries
- `pos.php` — POS: checkout at cart
- `sales.php` — Sales at receipts
- `products.php` — Pang add, edit, activate ng products at pang record ng bagong stock (Stock In)
- `sensors.php` — Sensor readings. Dito rin nagpo-POST yung sensor (`key`, `room_id`, `temperature`, `humidity`)
- `sql/sailor_pets.sql` — Database tables, triggers at views
- `assets/` — Bootstrap at product images
